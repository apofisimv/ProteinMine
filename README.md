# 🧬 ProteinMine

Telegram Web App игра с геолокацией и картами

## Особенности
- ⛏️ Майнинг протеинов
- 🗺️ Интерактивная карта с Leaflet.js
- ⚡ Система энергии
- 📊 Уровни и опыт
- 📍 Геолокация игрока

## Технологии
- Python (aiogram)
- Leaflet.js
- Telegram WebApp API
- SQLite

## Запуск
```bash
python3 bot.py
```
